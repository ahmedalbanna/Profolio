# **App Name**: Profolio

## Core Features:

- Dynamic CV Display: Dynamically renders CV sections such as experience, education, and skills, with clean formatting and easy navigation.
- Interactive Project Gallery: Showcase projects with detailed descriptions, images, and multimedia, allowing users to explore each project thoroughly.
- Secure Admin Panel: Provide a secure admin interface for managing and updating CV content, project details, and other portfolio information.
- Integrated Contact Form: Implement a contact form that allows visitors to send messages directly, with validation and spam protection.

## Style Guidelines:

- Primary color: Deep blue (#224263) to convey professionalism and trustworthiness.
- Background color: Light gray (#E0E0E0) for a clean, modern look that enhances readability.
- Accent color: Soft white (#F8F8FF) to highlight key elements and provide visual contrast.
- Font pairing: 'Inter' sans-serif for both headings and body, creating a neutral, machined aesthetic suitable for a portfolio website.
- Minimalist layout with ample whitespace to focus user attention on content and maintain a professional appearance.
- Use simple, line-based icons to represent skills and categories, aligning with the minimalist design approach.
- Subtle animations such as fade-in effects on page load and smooth transitions between sections to enhance user experience.
